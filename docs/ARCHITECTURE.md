# Architecture

FreeDisplay is a SwiftUI `MenuBarExtra(.window)` app. Layers: **Views → Services → system frameworks** (CoreGraphics, IOKit, ColorSync, private CGVirtualDisplay / IOAVService / DisplayServices / OSDUIHelper). `Models/` holds plain data. There is no separate ViewModel layer: views observe services and `DisplayInfo` directly.

## Layout

```
FreeDisplay/
├── App/            FreeDisplayApp (@main, MenuBarExtra scene), AppDelegate (owns DisplayManager; single instance, startup, sleep/wake observers)
├── Models/         DisplayInfo (per-display @Published state), DisplayMode, DisplayPreset, ArrangementLayout (pure arrangement geometry)
├── Services/       All system interaction; @MainActor singletons (`static let shared`)
├── Views/          SwiftUI views; MenuBarView is the root container (and defines ExpandableRow and the shared
│                   Disclosure animation), DisplayDetailView the per-display panel
├── Utilities/      NSScreen extensions (displayID ↔ NSScreen)
└── FreeDisplay-Bridging-Header.h   Private API declarations (CGVirtualDisplay, IOAVService)
```

The project file is generated by XcodeGen from `project.yml`; every `.swift` file under `FreeDisplay/` is included automatically.

## Services

| Service | Responsibility |
|---|---|
| `DisplayManager` | Enumerates displays, handles hot-plug/moves via `CGDisplayRegisterReconfigurationCallback` (coalesced), detects a display ID that now belongs to another monitor, opt-in "external above built-in" auto-arrange, wake restore, gamma reapply triggers. Pushes the display set to DDCService (candidates), BrightnessKeyService and PresetService. Owned by `AppDelegate` |
| `DDCService` | DDC/CI over I2C: IOAVService (`DCPAVServiceProxy`) on Apple Silicon, IOFramebuffer I2C on Intel. Scored service↔display matcher, coalesced writes (latest value wins, 50 ms command spacing), 5 s VCP read cache, retries, validated replies. Thread-safe (own queue + lock) |
| `BrightnessService` | Unified brightness, published per display as `DisplayInfo.brightnessControl`: native backlight via DisplayServices (`dlsym`; built-in panel and Apple displays; IOKit on Intel), DDC (VCP 0x10), or a software factor that `GammaService` multiplies in. Smooth animations, request IDs so stale outcomes are ignored, debounced persistence |
| `GammaService` | **Sole writer** of `CGSetDisplayTransferByFormula/Table`: image adjustment × night tint × software brightness, composed on top of the profile's `vcgt` calibration curve. Only writes displays with active state; restores the profile curve at quit |
| `NightModeService` | Night mode (off / on / scheduled) with fades; sets the tint in `GammaService` |
| `AutoBrightnessService` | Follows built-in screen brightness and applies it to externals; 30 s cooldown after manual changes |
| `BrightnessKeyService` | `CGEvent` tap (on its own thread) that routes brightness keys to the display under the cursor |
| `BrightnessHUDService` | Shows the native brightness OSD through the private `com.apple.OSDUIHelper` XPC service |
| `ResolutionService` | Switches display modes (`.permanently`); restores modes that changed during sleep |
| `HiDPIService` | Adds/removes the `scale-resolutions` key of override plists in `/Library/Displays/Contents/Resources/Overrides/` (other keys kept; new files start from Apple's override; one-time admin prompt via `NSAppleScript`); remembers per-monitor opt-outs |
| `VirtualDisplayService` | Creates/destroys `CGVirtualDisplay` instances (owned by the process, destroyed on quit) |
| `ArrangementService` | Applies display positions and the main display in one `.permanently` transaction |
| `ColorProfileService` | Lists (cached; rescans when a profile folder changes) and applies RGB display ICC profiles (ColorSync) |
| `NotchOverlayManager` | Black overlay in the notch display's menu bar row (below the menu bar items); saved per display, follows screen changes |
| `PresetService` | Saves/applies display presets (`~/Library/Application Support/FreeDisplay/presets.json`) |
| `SettingsService` | UserDefaults persistence and one-time migration of old keys; also hosts `AppLanguage`, `LanguageStore` and `L(_:_:)` |
| `LaunchService` | Launch at login via a per-user launchd agent in `~/Library/LaunchAgents`. Turning it on takes effect at next login; a manually opened copy hands over to the agent at launch |
| `UpdateService` | Checks GitHub Releases for a newer version |
| `CGHelpers` | `runWithTimeout` — runs blocking WindowServer calls off the main thread with a timeout; `framebufferPort` — `CGDisplayIOServicePort` resolved at runtime (Intel) |

## Key flows

```
Launch:    AppDelegate.init → SettingsService.migrateLegacyDefaults → DisplayManager()
           applicationDidFinishLaunching → single-instance check (a launchd instance waits
           for the replaced one to quit) → LaunchService.prepareAtLaunch (a manual copy that
           hands over to the agent waits 5 s for its replacement) → startServices:
           DisplayManager.start, brightness keys, NightMode, notch overlay restore,
           AutoBrightness, VirtualDisplay, sleep/wake/color-space observers, update check

Hot-plug / move / mode change:
           CG reconfiguration callback → DisplayManager.handleReconfiguration (150 ms coalesce)
           → refreshDisplays (identity check; forgotten IDs: DDC/Brightness/Gamma.forgetDisplay;
             bounds, main, names; publishes only on change) → DDC candidates, managed key
             displays, preset match → views re-render
           → every reconfiguration: gamma reapply passes (0, 0.5, 2 s; a completed configuration
             resets transfer tables); opt-in auto-arrange only for add/remove/mode

Arrange:   ArrangementView drag → ArrangementLayout.snap (flush, no overlap, connected)
           → ArrangementService.apply(frames, mainID) — one transaction, main at (0,0)

Sleep:     NSWorkspace.willSleepNotification → ResolutionService.snapshotModesBeforeSleep
Wake:      NSWorkspace.didWakeNotification → DisplayManager.reapplyDisplayStateAfterWake
           → gamma reapply right away (no full-brightness flash) → after 2.5 s (cancellable):
           refreshDisplays → restoreModesAfterWake → re-probe DDC → gamma reapply passes
Screens:   screensDidWakeNotification / NSScreen.colorSpaceDidChangeNotification
           → debounced gamma reapply passes (color space: calibration curves re-read)

Brightness: slider / keys / auto brightness → BrightnessService (request ID, animation)
           → native backlight | DDCService.writeAsync (coalesced) | GammaService (software)
           → DisplayInfo.brightness / brightnessControl (published)
Brightness keys: CGEvent tap thread → display under cursor (managed set) → main actor
           → BrightnessService.setBrightnessSmooth (steps from the pending target)
           → BrightnessHUDService (native OSD)

DDC matching (Apple Silicon): DCPAVServiceProxy's parent is named `dispextN:…`; the sibling
           `dispextN` → IOMobileFramebufferShim holds DisplayAttributes.ProductAttributes.
           Pairs are scored (vendor, product, real serial, name); index pairing only when one
           service and one display remain. Map cached with a 10 s negative TTL
```

Per-display settings are keyed by display UUID (`DisplayInfo.displayUUID`), never by `CGDirectDisplayID`. In-memory per-ID state is dropped through `forgetDisplay(_:)` when an ID goes away or changes monitor.

## Localization

UI strings are inline Turkish/English pairs: `L("Ayarlar", "Settings")`. `LanguageStore` is a hand-written `Observable`, so any view that calls `L` re-renders when the language changes. The choice is stored under `fd.language` (default: Turkish). Code, comments and docs are in English.

## High-risk files

| File | Why |
|---|---|
| `Models/DisplayInfo.swift` | Every view and service depends on it; grep all references when changing properties |
| `Services/DisplayManager.swift` | Global display list + hot-plug callback; test with plugging/unplugging |
| `Services/DDCService.swift` | Base of all external-display control; test on real hardware |
| `Services/GammaService.swift` | Shared gamma table owner; changes affect brightness, night mode, image adjustments and calibrated profiles |
| `Services/BrightnessKeyService.swift` | Active event tap filtering every media key in the session; runs on its own thread |
| `Views/MenuBarView.swift` | Root container; check panel sizing on macOS 27 (it sizes to the content's minimum size) |
